# AI promotion discoveries (review queue)

The automated watcher opens review pull requests here. These are **unverified pointers**, not public deal recommendations. First run initializes a baseline; follow-up runs identify changes and new official links.

Account-specific offers behind PayPal/ChatGPT/Claude/Perplexity logins cannot be detected by this public watcher. See `../ai-subscription-savings.md` for where users can check manually.
